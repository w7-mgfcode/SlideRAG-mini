## Error Budget Policy

When error budget falls below 50%:
- Freeze non-critical feature work
- Focus on reliability improvements
- Require Platform Lead review for any prod changes

When error budget is exhausted:
- Feature freeze until next month
- Post-mortem required for all SEV1/SEV2 incidents this month
- Architecture review for systemic reliability improvements
